# Controle de Brilho Avançado (Advanced Brightness Control)

Uma interface deliberadamente não convencional e divertida para ajustar o brilho do monitor no Windows, utilizando Python e Pygame.

Em vez dos sliders tradicionais, este projeto oferece uma grade com 101 *radio buttons* individuais (de 0 a 100) para você escolher o nível exato de brilho da tela com um único clique.

---

## 🚀 Funcionalidades

- **Ajuste Direto no Windows:** Comunicação nativa para alterar o brilho do monitor em tempo real.
- **Detecção Automática:** Lê o nível atual de brilho da tela assim que o programa é iniciado.
- **Design Não Convencional:** Grade interativa inspirada em memes clássicos de UI/UX.

---

## 🛠️ Tecnologias Utilizadas

- **Python 3**
- **Pygame** (Interface gráfica e gerenciamento de eventos)
- **screen-brightness-control** (Integração com as APIs de display do Windows)
